# Calculator

A fully functional web-based calculator with a modern dark UI.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Percentage and sign toggle
- Decimal point support
- Chained calculations
- Error handling (division by zero)
- Keyboard support
- Number formatting with commas
- Responsive design

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0–9 | Digits |
| . | Decimal point |
| + - * / | Operators |
| Enter or = | Calculate |
| Backspace | Delete last digit |
| Escape | Clear all |
| % | Percent |

## Usage

Open  in any modern browser — no build step required.

## Tech

Plain HTML, CSS, and JavaScript. Zero dependencies.
